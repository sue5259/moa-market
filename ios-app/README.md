# MOA 실험 앱 (iPhone · Expo Go) — Mac 사용 안내

iPhone 웹 브라우저로는 진동을 낼 수 없어서, 무료 앱 **Expo Go** 안에서 실험 페이지
(https://sue5259.github.io/moa-market/)를 열고 진동만 앱이 대신 실행합니다.
실험 화면·과제·데이터 저장은 GitHub에 올린 웹 실험과 완전히 같습니다.

## 폴더 안 파일
| 파일 | 용도 |
|---|---|
| `1-setup.command` | **처음 한 번만** 더블클릭 → 자동 설치 |
| `2-start.command` | **실험할 때마다** 더블클릭 → QR 코드 표시 (설치 후 바탕화면에 'MOA 실험 시작'으로도 복사됨) |
| `App.js` | 실험 앱 코드 (설치 파일이 자동으로 넣음) |

## 처음 한 번만 (약 20~30분)
1. iPhone에 App Store에서 **Expo Go** 설치
2. Mac에서 이 폴더의 **`1-setup.command`** 더블클릭
   - Node.js가 없으면 다운로드 페이지가 열립니다 → **LTS** 설치 후 `1-setup.command`를 다시 더블클릭
   - "✅ 설치 완료!"가 나오면 끝

## 실험할 때마다 (약 1분)
1. 바탕화면의 **'MOA 실험 시작'** 더블클릭
2. 같은 Wi-Fi면 그냥 Enter, 다른 Wi-Fi(또는 QR로 안 열리면) `t` + Enter
3. 나온 **QR 코드**를 iPhone **카메라**로 비춤 → Expo Go에서 실험 앱이 열림
   (두 번째부터는 Expo Go 첫 화면 최근 목록에서 눌러도 됨)
4. 실험이 끝날 때까지 터미널 창과 Mac을 켜 둠 (실험 중 Mac은 자동으로 잠들지 않음). 끝나면 창 닫기

## "악성 코드가 없는지 확인할 수 없습니다" 경고가 뜨면 (처음 한 번)
Apple 인증을 받지 않은 파일이라 Mac이 막는 것입니다. **터미널로 실행하면 바로 됩니다.**
1. `⌘ + Space` → `터미널` 입력 → Enter
2. 터미널 창에 `bash ` (bash 뒤에 띄어쓰기 한 칸)을 입력
3. `1-setup.command` 파일을 터미널 창 위로 끌어다 놓고 Enter

설치가 끝나면 이 폴더와 바탕화면 'MOA 실험 시작' 파일의 경고 표시가 자동으로 풀려서, 다음부터는 더블클릭으로 열립니다.
(다른 방법: 시스템 설정 › 개인정보 보호 및 보안 › 아래쪽 **"그래도 열기"**)

학교 Wi-Fi는 기기끼리 연결을 막는 경우가 많습니다. QR을 찍어도 안 열리면 `t`(다른 Wi-Fi 모드)로 시작하세요.
Mac이 "들어오는 네트워크 연결을 허용할까요?"라고 물으면 **허용**을 누르세요.

## iPhone 설정 체크
- 설정 › 손쉬운 사용 › 터치 › **진동** 켜기
- 설정 › 사운드 및 햅틱 › **햅틱 → 항상 재생**
- 미디어 볼륨 올리기, 저전력 모드 끄기, 방해 금지 모드 켜기

## 동작 확인 (실험 전)
1. 앱 시작 화면에서 **MOA Market 로고를 3초 안에 5번** → 연구자 모드
2. 진동 방식이 **실험 앱 진동 (vibrate)** 인지 확인
3. **VH 테스트** → 진동 + "앱 진동 실행 확인 (○ms)", **VA 테스트** → 소리
4. **참가자 화면으로** → 실험 시작

## 데이터
- 데이터는 **Expo Go 앱 안**에 저장됩니다 (Safari와 별개). Expo Go를 지우면 데이터도 사라집니다.
- 세션마다 연구자 모드 **CSV 다운로드(공유)** / **JSON 백업(공유)** → AirDrop·메일·파일 앱으로 내보내기
- CSV `hapticTriggered=1` = 앱이 진동 실행을 확인해 돌려준 경우, `hapticAckLatencyMs` = 요청→확인 시간(ms)

## 진동 종류 바꾸기
웹 쪽 `app.js` 상단 `WARNING_HAPTIC_NATIVE_STYLE` 값을 바꿔 GitHub에 올리면 됩니다 (앱 재설치 불필요).
`vibrate`(기본, 약 0.4초) · `heavy`(강한 짧은 탭) · `warning`(경고형 햅틱)

## 문제 해결
- **"incompatible with this version of Expo Go"**: App Store에서 Expo Go 업데이트 후 다시 시도
- **"실험 페이지를 불러오지 못했습니다"**: iPhone 인터넷 확인 후 '다시 시도'
- **소리가 안 남**: 무음 모드 해제, 미디어 볼륨 확인
- 설치 중 ❌가 나오면 터미널 창을 캡처해서 보내 주세요

- 처음 인터뷰 시작 시 iPhone이 "Expo Go가 마이크에 접근하려고 합니다"를 물으면 **허용**
- 녹음 파일은 Expo Go 앱 안에 저장됩니다. 연구자 모드 › 참가자 › 인터뷰 › **공유**로 질문별 m4a를 AirDrop/파일 앱에 보관하세요
